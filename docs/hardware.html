Hardware Modding & eFuse Preparation

Technical reference for building the KomaBon multi-format manga e-reader on the Seeed Studio XIAO ESP32-S3 TRMNL 7.5" DIY Kit.

CRITICAL SILICON PREPARATION
GPIO39, 41, and 42 overlap with the ESP32-S3 hardware JTAG controller. If left untouched, USB connection or soft reboots will trigger debug signals on these lines and corrupt MicroSD initialization. You must blow the DIS_PAD_JTAG eFuse.

1. Mandatory eFuse Burn Procedure

This is a permanent silicon-level OTP (One-Time Programmable) operation that disables hardware JTAG pad multiplexing without affecting USB flashing, CDC logging, or Wi-Fi OTA.

Execution Steps:

  1. Install esptool: 
    pip install esptool
  2. Verify current register (Read-Only): 
    python -m espefuse --port <PORT> summary
    Ensure DIS_PAD_JTAG (BLOCK0) is currently False.
  3. Burn the fuse: 
    python -m espefuse --port <PORT> burn_efuse DIS_PAD_JTAG
    Type BURN in uppercase when prompted to confirm.
  4. Cold Reset: Unplug the USB cable completely for 5 seconds and reconnect.

2. Wiring & Pinout Matrix

Target Pin Function Physical Connection Engineering Note
GPIO 39 SD_CS XIAO Pin 16 (Castellated Pad) Driven HIGH at startup to keep SD in High-Z (Alt: Font Chip U6 Pin 1)
GPIO 41 SD_SCK NFC1 / RX1 Pad (J4) Twist tightly with GND lead
GPIO 42 SD_MOSI NFC2 / TX1 Pad (J4) Dedicated SPI2 bus
GPIO 8 SD_MISO Castellation Pin 10 Internal pull-up enabled
GPIO 2 JOY_ADC KEY1 Switch Signal Pad ADC1_CH1 ladder. Do not pull up digitally!

3. Assembly & EMI Shielding

  • Wire Length: Keep all flying leads under 5–6 cm.
  • Decoupling: Solder a 100nF to 1µF ceramic capacitor directly across the MicroSD module VCC and GND pins.
  • Inductor Clearance: Route the SPI ribbon away from the carrier board's PMIC inductor (L1) to prevent charging spikes from coupling into data lines.
  • PSRAM Protection: Do not probe or attach anything to GPIO33–37 (120MHz Octal PSRAM bus).
