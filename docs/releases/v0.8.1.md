# 🌟 Highlights & New Features in v0.8.1

KomaBon v0.8.1 consolidates the major typography, bookmarks, and navigation engine introduced in v0.8.0, bringing immediate in-reader settings persistence, enhanced storage efficiency, and critical security and license alignments.

## 🛠️ Enhancements & Maintenance in v0.8.1

- **Instant In-Reader Settings Persistence:** Adjusting font size, font family, margins, or justification from the reader's Quick Settings Overlay now persists immediately to `/reader_config.json`, keeping preferences intact across book switches and reboots.
- **Optimized Storage & Filesystem Footprint:** Stripped redundant font files from the LittleFS partition image (freeing over 214 KB / 50% flash space in the web filesystem), as reading fonts are embedded directly in firmware PROGMEM.
- **Security & Integer Overflow Remediation:** Explicitly cast memory allocation sizing across `stb_truetype.h`, `TrueTypeEngine.cpp`, and comic page buffers to `size_t`, resolving all upstream GitHub CodeQL security alerts (`cpp/integer-multiplication-cast-to-long`).
- **Complete Open Source Licensing:** Added official Atkinson Hyperlegible (SIL OFL 1.1) license attribution to `docs/OFL.txt` and internal font manifests.
- **Tooling & Build Hygiene:** Aligned `.clang-format-ignore` patterns to protect all generated bitmap icon headers and embedded vector tables.

---

## 🔤 TrueType Vector Typography & Layout (from v0.8.0)

- **Dynamic TrueType Vector Engine:** Integrated high-performance vector font rendering powered by `stb_truetype`, deprecating monolithic legacy bitmap arrays (-14,400 LOC) and freeing substantial flash storage.
- **Expanded Font Library:** 6 curated font families (Atkinson Hyperlegible, Merriweather, Literata, Source Serif 4, Gelasio, Open Sans).
- **Granular Font Sizing:** 6 distinct sizes (8pt, 10pt, 12pt, 14pt, 16pt, and 18pt) with proportional airy line height.
- **Customizable Page Margins:** Selectable Narrow (20px), Medium (35px), and Wide (50px) reading margins.
- **Full Justified Text:** Dynamic word-spacing justification configurable across Reader Quick Settings, App Settings, and the Web UI.

## 🔖 Hardware-Integrated Bookmarks System

- **Quick-Toggle Gesture:** Hold the joystick **UP** (≥600ms) during reading to instantly bookmark or unbookmark the current page.
- **Top-Left Ribbon Indicator:** Elegant swallowtail ribbon icon rendered at 24px from the top-left margin with instant partial e-ink refresh.
- **Bookmarks Management Overlay:** Hold the joystick **RIGHT** (≥600ms) or select *Bookmarks...* in Quick Settings to browse, jump, or delete bookmarks.
- **Atomic Storage:** Thread-safe atomic writes to `/bookmarks.json` on non-volatile storage protecting against sudden power loss.

## ⏩ Interactive "Go to Page" Slider

- **Rapid Navigation:** Push the joystick **DOWN** in-reader to open an interactive scrubber overlay.
- **Dual-Speed Stepping:** **Left / Right** for fine ±1 page stepping, **Up / Down** for rapid ±10 page jumps.
- **Universal Support:** Works seamlessly across both `.kmb` Manga archives and `.epub` dynamic chapters.

## ⚡ Display, Library & Web UI Enhancements

- **A2 Fast Refresh:** Zero-flicker rapid waveform for fluid, ghosting-free navigation in Main Menu and Bookshelf.
- **Manga Volume Grouping:** 2-level hierarchical grouping with natural alphabetical and numerical sorting.
- **IndexedDB Cover Cache:** Client-side cover caching in browser (`KomaBonCovers`), eliminating SD bus saturation and DOM freezes.
- **Semantic 4-Tab Web Settings:** Streamlined web dashboard with multi-column auto-saving preferences.
