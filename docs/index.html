Device does not appear?

Hold the BOOT button, tap RESET, then release BOOT and try connecting again.

What hardware modifications are expected?

KomaBon is heavily optimized for a TRMNL 7.5" (OG) DIY Kit that has been manually modified with a 5-way analog joystick (wired in parallel to Button 1 / GPIO2) and a MicroSD module (using the SPI2 bus).

What happens on unmodified (stock) hardware?

If you flash KomaBon on a stock TRMNL board without the joystick or SD card, the operating system will boot and remain completely stable. However, UI navigation will be severely limited, as you will only have the single built-in button available instead of full directional controls. The system will automatically use the 10 MB internal storage fallback for your ebooks.
