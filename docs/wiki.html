📖 KomaBon Documentation

KomaBon (from Koma: manga panel, and Bon: book) is an ultra-optimized, open-source E-Ink operating system engineered for the Seeed Studio XIAO ESP32-S3 TRMNL 7.5" DIY Kit.

⚡

Zero-Decryption E-Ink

Direct 1-bit bitmapped rendering with Atkinson dithering and adaptive waveform partial updates.

🎮

5-Way Tactile Joystick

Physical directional navigation with debounced deadzone filtering and rapid multi-item skipping.

💾

Dual-Filesystem Design

External MicroSD on dedicated SPI2 bus paired with protected internal flash partitions.

🌐

Universal Client Converter

Converts CBZ, PDF, EPUB, and ODT entirely in browser JavaScript with smart margin cropping.

Unlike generic e-readers that struggle to parse heavy manga archives or large EPUB files on resource-constrained microcontrollers, KomaBon takes an architectural split: all CPU-heavy decompression, page layout, image scaling, margin cropping, and dithering are performed client-side inside the modern web browser. The device itself only receives pre-rendered, perfectly packed 1-bit binary streams, resulting in instantaneous page flips and days of battery life.

⚡ Installation & Flashing

KomaBon supports three official installation and upgrade methods:

1. Browser Web Flasher (Recommended)

The fastest way to install or update KomaBon is using the official KomaBon Web Flasher via Google Chrome or Microsoft Edge on desktop. It uses the Web Serial API to communicate directly with your device over USB without requiring any software installation.

ℹ️ Update vs. Setup New Hardware
  • Update existing KomaBon: Writes only the active firmware and LittleFS partitions. Keeps your Wi-Fi credentials, book library, and reading progress intact.
  • Set up new hardware: Performs a complete initial write including bootloader, partition table, firmware, and Web UI.
⚠️ "Erase Device" Checkbox Warning
When updating an existing installation, never check the "Erase device" box, or your Wi-Fi credentials and local system settings will be wiped. Erasing is only safe when preparing a brand new, unprogrammed board.

2. Local Flashing via PlatformIO

If you are building from source or developing custom features, you can flash via PlatformIO CLI or VS Code:

# 1. Clone repository
git clone https://github.com/alessandroabbasciano-cpu/KomaBon.git
cd KomaBon

# 2. Build and upload firmware binary
pio run --target upload

# 3. Build and upload LittleFS web assets
pio run --target buildfs
pio run --target uploadfs

# 4. Monitor live serial logs
pio device monitor -b 115200

3. Over-The-Air (OTA) Updates

Once connected to your local Wi-Fi, KomaBon can automatically check for updates against the GitHub Releases API. Updates are verified using Ed25519 cryptographic signatures; the device refuses to install any binary whose digest does not match the official project key.

🚀 First Boot & Device Setup

When powering up KomaBon for the first time:

  1. Hardware Diagnostics Screen: The e-paper screen renders a boot banner displaying MicroSD status (Mounted or Failed), Joystick calibration state (Calibrated or Default), and Battery percentage.
  2. Automatic Wizard Routing: If no calibration file (/joy_cal.json) is found on the filesystem, KomaBon automatically routes you directly into the Hardware Calibration Wizard.
  3. Offline Management Hotspot: If no known Wi-Fi network is reachable, KomaBon broadcasts an offline management access point:
    • SSID: KomaBon
    • Password: Displayed on screen or generated from hardware MAC
    • IP Address: http://192.168.4.1/

🛠️ Hardware Modding & Wiring Guide

KomaBon is built on top of the TRMNL 7.5" OG DIY Kit carrier board paired with a Seeed Studio XIAO ESP32-S3 Plus module. To support a massive library and precise physical navigation, two hardware modifications are required:

  1. Wiring an external MicroSD card module onto dedicated SPI2 hardware pins.
  2. Wiring a 5-way analog joystick in parallel to KEY1 (GPIO2 / ADC1_CH1).

🔥 Mandatory Step: Burning the DIS_PAD_JTAG eFuse

🚨 CRITICAL SILICON REQUIREMENT
On ESP32-S3 silicon, GPIO39 (MTCK), GPIO41 (MTDI), and GPIO42 (MTMS) are multiplexed with the internal USB-Serial-JTAG debugging controller. Connecting a USB cable or performing a software reset pulls these pins into debug state, which permanently locks up the MicroSD SPI bus. You MUST burn the DIS_PAD_JTAG eFuse to free these pads!

eFuse Burning Step-by-Step:

# 1. Install Espressif tool
pip install esptool

# 2. Check current eFuse status (Read-Only)
python -m espefuse --port <YOUR_COM_PORT> summary

# Look for DIS_PAD_JTAG:
# DIS_PAD_JTAG (BLOCK0) = False R/W (0b0)

# 3. Permanently burn the eFuse (IRREVERSIBLE OPERATION)
python -m espefuse --port <YOUR_COM_PORT> burn_efuse DIS_PAD_JTAG

# Type BURN in capital letters when prompted.

# 4. Perform a cold reboot: Unplug USB for 5 seconds and reconnect.
💡 What does burning this eFuse change?
USB firmware flashing, serial monitoring (115200 baud), and OTA updates remain 100% functional. The only feature permanently disconnected is JTAG hardware breakpoint debugging on those three specific pins.

🚫 Strict Octal PSRAM Rule (GPIO 33–37)

⛔ ABSOLUTE RULE: NEVER TOUCH GPIO 33 THROUGH GPIO 37
The Seeed XIAO ESP32-S3 Plus board uses an 8MB Octal PSRAM chip running at 120MHz over pins GPIO 33, 34, 35, 36, and 37 (qio_opi mode). Soldering to these pins or declaring them in code causes immediate silicon bus collisions, memory watchdog panics, or unrecoverable board failure.

🔋 Power Management & Battery ADC

Battery voltage is monitored through a dedicated resistor divider on GPIO 1. The firmware uses the factory eFuse ADC calibration curves (analogReadMilliVolts()) for millimeter-accurate battery percentage calculation across 3.00V (Empty) to 4.20V (Full).

⚡ Rapid Input Engine & Debouncing (New in v0.6.0)

E-paper displays require 300–450 ms of physical hardware refresh latency. In older versions, pressing the joystick rapidly 3 times would trigger an intermediate refresh on item 1, freeze the interface, and then jump to item 3.

KomaBon v0.6.0 introduces an advanced decoupled input engine:

  • 80 ms Deadzone (JOY_COOLDOWN_MS): Replaces the older 200 ms lockout, instantly accepting rapid double- and triple-clicks without losing strokes.
  • 250 ms Lazy Render Window (LAZY_RENDER_DEBOUNCE_MS): Holds screen redraws in memory while the user continues moving. If you tap 3 times quickly, the menu cursor advances 0 → 1 → 2 → 3 in RAM, and only one single e-ink refresh occurs on the final target!
  • Queue Guard (hasPendingActions()): Guarantees that the display controller never starts drawing a frame if unhandled input events remain queued.

🎯 Joystick Calibration Wizard

Because analog resistor tolerances vary across joystick modules, KomaBon includes a built-in calibration utility accessible via Settings → Calibrate Joystick:

  1. The screen displays real-time ADC raw values.
  2. Follow the on-screen prompts: click Center, push Up, push Down, push Left, push Right.
  3. The calibrated center points are saved permanently to /joy_cal.json on external storage and loaded automatically on boot.

🌐 Web Interface (Web UI)

Connect your computer or smartphone to the same Wi-Fi network and open http://<KOMABON_IP>/ in any browser to access the device management suite.

1. Dashboard & Storage Recovery

The Dashboard displays live device telemetry: battery voltage, percentage, active Wi-Fi network, storage utilization, and firmware version.

🛠️ MicroSD Bus Remount Badge
Located directly beneath the Universal Converter, the Remount SD Bus button allows you to re-initialize the external MicroSD SPI2 controller without rebooting the reader. If you swapped cards or experienced an SPI bus glitch, clicking this button immediately restores library access.

2. Modern Library with Chunked Virtual Scroll

To ensure lightning-fast performance even with libraries of 500+ books, the Web UI uses an IntersectionObserver-driven chunked renderer (30 items per batch). Memory usage stays minimal, and scrolling remains butter-smooth on mobile devices.

3. Ghost Node Architecture (Missing Files)

If a book was previously read but its file is no longer present on the MicroSD card (e.g. card swapped, corrupted, or file renamed), KomaBon prevents data loss:

  • The book is displayed with a semi-transparent card and a prominent FILE MISSING badge.
  • Your reading progress (page number, chapter) is preserved in ProgressStore.
  • If you delete a ghost book from the Web UI, the system cleanly removes the orphaned metadata, progress records, and book order entries without VFS errors.

4. Manga Series Grouping (Accordions)

Multi-volume manga series (e.g., Berserk Vol. 01, Berserk Vol. 02) are automatically grouped into clean, expandable accordion cards. In-memory instant search expands matching series dynamically as you type.

5. Zero-Latency SWR Cache

Switching to the Library tab renders instantly (0 ms) using cached data stored in browser sessionStorage. The interface revalidates data with the ESP32 in the background; if files were added or removed, the DOM updates seamlessly without visual flicker.

📚 Universal Manga & Document Converter

Embedded directly into the Web UI dashboard, the Universal Converter transforms complex documents into pure 1-bit E-Ink optimized formats without sending data to any external server.

Supported Input Formats

  • CBZ & ZIP: Comic and manga image archives.
  • EPUB: Standard e-books (extracts text, formatting, and chapter images).
  • PDF: Document pages rasterized and scaled at high DPI.
  • ODT: OpenDocument text documents.

Smart Margin Cropping & Atkinson Dithering

Raw manga scans often have large white margins that waste valuable E-Ink screen space. KomaBon's converter executes an intelligent edge-detection pass (getCropBounds) to eliminate whitespace and center the artwork to fit the 800 × 480 panel.

Grayscale and color images are translated into binary black-and-white using Atkinson Dithering, preserving delicate line art, screentones, and gradients without the harsh clustering artifacts typical of Floyd-Steinberg dithering.

Smart Panel Focus Mode (AI & Gutter Detection)

For readers who prefer reading individual panels zoomed-in to full screen, the converter provides Panel Focus Mode:

  • AI Panel Detector (YOLO26-nano): An in-browser neural network fine-tuned on manga layouts that identifies individual panel frames, speech balloon relationships, and complex action sequences. Hardware-accelerated via WebGPU and WebAssembly SIMD.
  • Smart Gutter Splitter (Fallback): A mathematical white-space projection algorithm that slices grid-based pages along whitespace gutters with zero external downloads.
  • Authentic Reading Order: Graph-based topological sort automatically sequences detected panels according to genuine reading order: RTL (Right-to-Left) for Japanese manga or LTR (Left-to-Right) for Western comics.
  • Natural Upright Scaling & Text Protection: Automatically scales panels to fit the screen while keeping text and artwork right-side up. Speech bubbles straddling borders are dynamically included to prevent cut dialogue, with optional 90° rotation for wide landscape panels.
  • Configurable Padding & Overview: Adds custom safety margins (default 3–5%) around panel bounding boxes and supports an optional full-page overview before panel sequence.

The .kmb Binary Comic Format

For maximum reading performance, comics are exported as .kmb (KomaBon Manga Binary) files:

  • File Header: KMB1 magic signature + width, height, and page count.
  • 1-Bit Bitmaps: Pure 1-bit packed byte arrays (1 bit per pixel: 800×480 is only 48,000 bytes per page).
  • Embedded Thumbnails: Automatically includes pre-rendered 60×80 and 120×160 thumbnails for instant library loading.
  • Reading Speed: The ESP32 streams pages directly from SD card into display buffer via DMA in under 15 milliseconds!

JSON Configuration Schema

User configuration and reading state are preserved across reboots in structured JSON files:

  • /progress.json: Maps book titles to current chapter, node index, character offset, and global page.
  • /book_order.json: Persists custom user drag-and-drop book sorting order.
  • /joy_cal.json: Contains calibrated ADC thresholds for Center, Up, Down, Left, and Right.
  • /reader_config.json: Stores font family (FreeSans, Merriweather, Literata, etc.), font size, and refresh frequency.

🔧 Troubleshooting & FAQ

MicroSD Card Not Detected / Mount Fails

  1. Check eFuse: Verify that DIS_PAD_JTAG was burned. If unburned, the USB debugger locks the bus.
  2. Wiring Integrity: The SCK line (GPIO 41) must be twisted with a GND wire to suppress high-frequency SPI reflections.
  3. Card Format: Ensure your card is formatted as FAT32 or exFAT with MBR partition table.
  4. Storage Recovery: Click "Remount SD Bus" from the Web UI Dashboard.

Ghosting on E-Ink Display

Monochrome electrophoretic displays naturally accumulate particle drift after multiple partial updates. Press the physical KEY2 button once to force an immediate full-waveform screen refresh. You can also configure the automatic refresh frequency (every 5, 10, or 20 pages) in the Reader Settings overlay.

Joystick Direction Feels Sticky or Skips

Run the on-screen Calibration Wizard from the Settings menu. With the v0.6.0 update, rapid inputs now benefit from 80 ms deadzones and 250 ms quiet-period rendering, eliminating intermediate freezes.
